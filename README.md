# Car Dealership Full Stack Application

**Repository Name:** xrwvm-fullstack_developer_capstone

**Project Name:** Car Dealership Full Stack Application

## Project Description

This project is a full-stack web application for a car dealership. It allows users to browse car dealerships, view dealer details, explore car makes and models, register and log in, and submit reviews for dealerships.

## Technologies Used

- React.js
- JavaScript
- Python
- Django
- Node.js
- Express.js
- MongoDB
- HTML and CSS

## Features

- User registration and login
- Browse all car dealerships
- Search dealerships by state
- View dealership details and customer reviews
- Submit dealership reviews
- View car makes and models
- Sentiment analysis of customer reviews
